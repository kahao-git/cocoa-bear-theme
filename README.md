# Xiaomi 海外主题作品集 · 主题设计

这里收纳两套为小米海外版（HyperOS 3）制作的完整主题，每套都按「预览图 / 封面 / 说明 / 校验清单 / 分层 PSD」的统一结构放在各自目录里。

## 目录

| 目录 | 主题 | 风格 | 预览 |
| --- | --- | --- | --- |
| `主题/001 - 卡通 IP 形象主题` | 可可小熊 · 秋季奶油暖色 | 毛绒小熊 IP、奶油米白 + 枫叶橙棕 | 640×1422 |
| `主题/002 - Moody Ocean 情绪海洋` | Moody Ocean 情绪海洋 | 电影感灰蓝海水、动态锁屏、磨砂玻璃 | 1080×2400 |

```

    └── Moody Ocean 情绪海洋_Layered_PSD.zip # 5 个分层 PSD
```

## 说明

- 两套主题均为海外版（Global）包，`resourceType=theme`、`uiVersion=17`、`miuiAdapterVersion=3.3`。
- `.mtz` 为不改签名的标准 zip 结构（根 `description.xml` + 各模块目录 + `preview/`），导入 HyperOS 3 海外版主题商店 / 主题编辑器测试使用。
- `Layered_PSD` 包中的 PSD 为 8 位 RGBA、1080×2400（001 为原始导出尺寸 640×1422），可在 Photoshop / Affinity Photo 中直接打开修改。
